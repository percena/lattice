# Align policy (portable; PCA method)

Shipped with skills that run principal batch confirm. **Method** is shared; **first-pass host is create-spec**. `start-work` uses this for greenfield **delegate** and **mid-EXECUTE** new principals — not as the sole first-pass grill home. No monorepo docs required.

## Rules

1. Few rounds (target ≤3, cap 5); **2–5 principal** questions per batch.  
2. Silent PREP: never ask diggable facts.  
3. Every principal has a **recommendation** + one-line trade-off.  
4. Secondary self-decide; list for override.  
5. Do not implement / open tickets / branches until first-pass aligned (unless only filling session COMMITTED for S).  
6. Prefer LOCKED summary before exit on broad work.  
7. Mid-EXECUTE: re-confirm only **new** principals — do not re-ask locked Spec Decisions.  
8. **C + large blast-radius only:** optional **codebase reality pass** before first-pass PCA (rewrite/migrate/overhaul/cross-module). Output → Spec/rev — **not** `docs/analysis/`. **Skip on S/M** unless escalating to C. Detail: co-installed `create-spec/references/policy.md`.

## Coupling test

> If I decide X alone, does core intent still probably succeed?  
> Yes → secondary. No/unclear → principal.

## Output

Why, In/Out, Acceptance, User-decided, Agent-assumed — enough to fill COMMITTED / Spec Decisions.
